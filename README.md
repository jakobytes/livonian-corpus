### README

This is a text corpus in progress based on collection of Livonian folksongs *Volkslieder der Liven* by Oskar Loorits, published in 1936 and scanned at the Tartu University Library [https://hdl.handle.net/10062/100817][1] with the licence 	Attribution-NonCommercial-NoDerivs 3.0 Estonia. The library is not allowed to change the lisence but the permission needs to be asked from Loorits’ relatives. *Until permission, the corpus cannot be shared or opened, but can be used for research purposes.*

**Traskribuksessa olevien aineistojen kuvaus**

*Volkslieder der Liven* is the most comprehensible collection of Livonian folksongs. According to Valts Ernstreist (oral communication) it comprises most of the known song types. In addition to songs, it also contains nursery rhymes, games and some prose stories. Most of the material was recorded by Loorits himself in handvwriting, but the book also contains materials from other early, also some transcriptions from phonographs.

The processing of the corpus has been done in the FILTER (PI. Kati Kallio & Eetu Mäkelä, Finnish Literature Society & University of Helsinki, in collaboration with the Estonian Folklore Archives) and REFOP (Kati Kallio, Finnihs Literature Society) projects funded by the Finnish Research Council at the Finnish Literature Society in 2023–2025. Research assistant Sakari Korpikallio created the first version and the xml structure, research assistant Mirjami Sipilä trained a Transcribus model for the book with the help of research assistant Jakob Lindström, and then Sipilä transcribed most of the book, and filled the metadata fields.

The book is published in German. The song texts are in Livonian, and some versions of similar songs or stanzas in Latvian are provided, if these were performed by the informants. German translations are provided (often one translation for several variants), and many songs also contain musical notations. 

This corpus only contains song texts in Livonian and their attached parallel versions in Latvian. The translations in German are not included. The book also contains lengthy introduction and attachments with contextual information about Livonians, collecting and the singers. These parts of the book are not included in the corpus.

The book is ordered by poem genres, poem types, and their versions. The poem types and their versions are numbered, very similar versions marked with alphabeths (e.g. 18: 3a): this is also the main reference used for the items. Some Latvian parallel versions are given their own number, some are just given as parallels to the Livonian texts without numbering. In the corpus, the main signum for each item is the poem type and version number in the book. Also the ID number is based on these. 

The signums given under each song, such as “Kr Melngailis 27 (38)” is a code that most typically gives an abbreviation of the village where the text has been recorded (Kr.), the surname of the collector if someone else than Loorits (Melngailis), and the number of the song (27) in the song index at the end of the book (pp.
